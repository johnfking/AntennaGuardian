# Security Policy

## Supported versions

Security fixes are applied to the latest published AntennaGuardian release.

## Reporting a vulnerability

Use GitHub's
[private vulnerability reporting](https://github.com/johnfking/AntennaGuardian/security/advisories/new)
for suspected vulnerabilities, signing misuse, or compromised releases.

Include the affected version, observed behavior, and reproduction details when
available. Do not include radio credentials or unnecessary private network
information. Reports will be acknowledged and investigated as promptly as
practical for a maintainer-run open-source project.
